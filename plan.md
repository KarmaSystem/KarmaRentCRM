# Rental Planner — план реализации

## Цель
Mobile-first Telegram Mini App для управления прокатом мототехники, автомобилей и недвижимости с PostgreSQL/Prisma, REST API, Telegram initData auth и Railway deployment.

## Дизайн
- **Движение:** compact utility dashboard — нативная плотность Telegram Mini App без декоративного шума.
- **Принципы:** полезная площадь, белые карточки на мягком фоне, ясные статусы, быстрые действия одним касанием.
- **Палитра:** navy для текста и заголовков, cyan/blue для активных элементов и подтверждённых броней, teal для нижней навигации, muted gray для вторичной информации.
- **Композиция:** липкая нижняя навигация и sticky-контролы, календарь как горизонтальная шахматка с фиксированной колонкой объектов.
- **Сигнатуры:** круглые бейджи статусов, цветные booking bars, компактные табы с активным cyan underline.
- **Взаимодействие:** каждая карточка кликабельна; свободный слот календаря открывает создание брони; расчёты стоимости обновляются сразу.
- **Анимация:** короткие 160–220ms transitions, без отвлекающих эффектов.
- **Типографика:** system sans; 11–12px labels, 14–16px body, 20–24px section headers.
- **Позиционирование:** «Rental Planner — операционный центр проката в одном Telegram-экране».

## Структура
- `app/` — страницы и route handlers REST API.
- `components/` — mobile UI и calendar.
- `lib/` — Prisma, Telegram auth, validation и бизнес-правила.
- `prisma/` — схема, миграции, seed.
- `bot/`, `workers/` — webhook и идемпотентные cron-уведомления.
- `tests/` — unit-тесты расчётов и overlap validation.
